# 🌍 AI Voice & Text Translation Assistant

An AI-powered **Voice & Text Translation Assistant** built using **Python**, **Flask**, **OpenAI Whisper**, and **Google Translate API**. The application translates both text and speech into multiple languages with a clean, responsive, and modern web interface.

---

# 📌 Project Overview

This project was developed as part of the **CodeAlpha Internship**.

The application enables users to:

* Translate text between multiple languages.
* Convert voice into text using AI-powered speech recognition.
* Listen to translated output using Text-to-Speech.
* Store translation history.
* Experience a responsive and modern web interface.

The goal of this project is to demonstrate practical implementation of Artificial Intelligence, Natural Language Processing, and Web Development in one complete application.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/choudharyasim0/YOUR_REPOSITORY_NAME.git
```

## Navigate to Project Folder

```bash
cd Task-01-AI-Voice-Text-Translation-Assistant
```

## Create Virtual Environment

```bash
python -m venv .venv
```

## Activate Environment

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Open in browser:

```text
http://127.0.0.1:5000
```

# 🔄 Workflow

1. Launch the application.
2. Select source language.
3. Select target language.
4. Enter text or record voice.
5. Click **Translate**.
6. Receive translated output.
7. Listen using Text-to-Speech.
8. Translation history is automatically saved.
